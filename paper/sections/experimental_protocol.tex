\subsection{Evaluation Setting}
All reported neural results are evaluated on held-out test windows using the checkpoint selected by validation performance. Metrics are computed only on artificially hidden positions that were observed in the original AWS record. We report normalized mean absolute error (MAE) and root mean squared error (RMSE), averaged over variables unless otherwise specified. Because all variables are standardized with train-window statistics before modeling, normalized MAE and RMSE are errors in units of the corresponding training-window standard deviation; Table~\ref{tab:raw-unit-errors} converts normalized errors to physical units for the gated ERA5 model.

The main block-missing experiments use three outage regimes: short blocks of 6--24 steps (18--72 h), medium blocks of 24--72 steps (3--9 d), and long blocks of 72--240 steps (9--30 d). Within each regime, block start position, block length, and affected variable are sampled randomly subject to the target missing rate. Missing rates are 20\%, 40\%, and 60\%, with three random seeds for each configuration; the resulting 27 runs per variant are the Cartesian product of three block regimes, three missing rates, and three seeds. The held-out station experiment evaluates transfer to five stations excluded from model training at 40\% block missingness.

Neural models are trained for at most 50 epochs with AdamW, learning rate $10^{-4}$, weight decay $10^{-4}$, batch size 32, and early stopping after 10 validation epochs without improvement. Test evaluation uses batch size 64. All neural training and evaluation runs are executed on the remote GPU server; local computation is limited to preprocessing, aggregation, plotting, and LaTeX compilation.

\subsection{Baselines}
We compare against five core baselines. Linear interpolation and last-observation-carried-forward test whether local temporal continuity is sufficient. ERA5 direct substitution fills missing positions with ERA5 values calibrated from training windows while preserving observed AWS values, testing the strength of reanalysis alone. The main Round 1 ERA5-direct baseline uses a train-only per-variable mean-bias correction, $\tilde{E}_{t,c}=E_{t,c}+\bar{b}_c$, where $\bar{b}_c$ is the mean AWS-minus-ERA5 difference over observed training positions. We also evaluate stronger ERA5-direct calibrations, including train-only global linear calibration and station-month-variable mean-bias correction with fallback to station-variable and global variable bias when training samples are insufficient. No validation or test labels are used to estimate any ERA5-direct calibration. SAITS provides an independent attention-based imputation baseline \citep{du2023saits}. It is trained with the same block-missing mask generator and evaluated on the same block-missing configurations as ECBIT, but it does not receive ERA5 inputs. The iTransformer imputation baseline tests a neural variate-token model without ERA5 conditioning \citep{liu2024itransformer}.

For fair ERA5-augmented controls, we add augmented SAITS and augmented iTransformer under the same 27 block-missing configurations. The SAITS variant uses a simple concatenated input containing AWS values, observation masks, time features, and aligned ERA5 covariates. The iTransformer variant uses the same variate-token backbone as the no-ERA5 iTransformer baseline, with ERA5 trajectories concatenated to the per-variable token features. These controls separate the value of external reanalysis information from the specific ECBIT gated-injection design.

We also implemented a BRITS wrapper \citep{cao2018brits}, but it is not part of the main result table. The reported third-party comparison uses SAITS as the independent deep imputer, with SAITS+ERA5 and iTransformer+ERA5 included as fair ERA5 controls.

\subsection{Ablations and Follow-up Analyses}
The primary ECBIT ablation compares gated ERA5 injection, concat/no-cross fusion, and no-ERA5 training under matched block-missing conditions. A no-blockmask variant trains with MCAR masks and is reported separately because its training distribution differs from the block-failure regime.

To explain the ERA5 signal, we run three follow-up analyses. First, block-length sensitivity varies the maximum outage horizon from 24 to 216 hours while comparing ERA5-conditioned and no-ERA5 models. Second, ERA5 variable masking replaces one ERA5 channel at inference time with its training-set mean to measure channel importance. Third, ERA5 temporal downsampling evaluates checkpoints trained with 3-hourly ERA5 under coarser inference-time ERA5 inputs, separating short-timescale sensitivity from the main training comparison.

\subsection{Reproducibility Artifacts}
We record the benchmark construction and result inventory as file-level artifacts. Station selection, ERA5 alignment validation, and preprocessing outputs are summarized by three CSV manifests: \texttt{station\_meta\_ecbit.csv}, \texttt{era5\_3h\_manifest.csv}, and \texttt{antaws\_impute\_manifest.csv}. The full window index records station identifier, split, start index, and start timestamp for each retained window. The same benchmark-protocol directory contains per-station window counts and realized block-length diagnostics.

All experiment configurations are kept as YAML files in the experiment configuration directory. Per-run result files, table-generating summaries, and local/remote environment snapshots are stored under the results directory. A compact inventory records paths, file sizes, and checksums for the retained artifacts. Together, these files allow the station split, window construction, mask diagnostics, calibration ablations, and raw result tables to be checked directly.
