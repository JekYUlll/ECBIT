\section{Methodology}

\subsection{Problem Formulation}
Let $X \in \mathbb{R}^{T \times C}$ be an AWS window with $T=168$ 3-hourly steps and $C=5$ variables: temperature, relative humidity, wind speed, pressure, and specific humidity. The window length corresponds to 21 days, long enough to contain multi-day sensor outages while still providing local temporal context on both sides of many gaps. Let $O \in \{0,1\}^{T \times C}$ denote the real observation mask, where $O_{t,c}=1$ means the station value is observed. ERA5 provides an aligned dense sequence $E \in \mathbb{R}^{T \times C}$ with the same variable ordering and timestamps.

All AWS and ERA5 variables are standardized before modeling. Normalization statistics are computed from training windows only and then reused for validation, test, and held-out station evaluation. This prevents test leakage while putting AWS and ERA5 variables on comparable scales. For AWS inputs, unobserved values are replaced by normalized zeros after masking; the binary observation and missingness masks carry the information needed to distinguish a true standardized zero from a missing value. During training and evaluation, we sample an artificial missing mask $A$ only from positions where $O=1$. The model input mask is
\begin{equation}
M = (1 - O) \lor A,
\end{equation}
and the supervised loss is computed only on $A$:
\begin{equation}
\mathcal{L} = \frac{\sum_{t,c} A_{t,c}(\hat{X}_{t,c}-X_{t,c})^2}{\sum_{t,c} A_{t,c}}.
\end{equation}
This avoids treating real unobserved values as ground truth. The model reconstructs the full window, but metrics are reported only on artificially hidden observed positions. This distinction is important for sparse Antarctic AWS records: historical gaps can be used as missing context, but not as labels.

\subsection{Block Missing Simulation}
Real AntAWS missingness is block-structured. We therefore sample contiguous outage blocks with three regimes: short gaps of 6--24 steps, medium gaps of 24--72 steps, and long gaps of 72--240 steps. At 3-hour resolution these correspond to approximately 18--72 h, 3--9 d, and 9--30 d. Missing rates are set to 20\%, 40\%, and 60\%. Blocks are sampled variable-wise by default, reflecting common sensor-level failures in which wind, humidity, pressure, or temperature can disappear without all variables failing simultaneously. A point-wise Missing Completely At Random (MCAR) mask, following the standard missing-data terminology of \citet{rubin1976inference}, is used only for the no-blockmask ablation.

For a given window, missing-rate target, and block-length regime, the simulator repeatedly samples a variable and a contiguous interval until the target number of artificially hidden observed positions is reached or no additional valid positions are available. Candidate labels are intersected with $O$ so that artificial labels never include truly missing raw observations. This procedure creates a controlled block-missing test set while preserving the original sparse context of each station window.

The implementation is deterministic given a seed and follows this procedure. First, compute the target label count as $\mathrm{round}(r\sum_{t,c}O_{t,c})$ for missing rate $r$. Second, while the accumulated artificial labels are below this target, sample a start time $u\sim\mathrm{Uniform}\{0,\ldots,T-1\}$, a requested block length $\ell\sim\mathrm{Uniform}\{\ell_{\min},\ldots,\ell_{\max}\}$, and a variable $c\sim\mathrm{Uniform}\{1,\ldots,C\}$. Third, clip the interval to the current window, $[u,\min(u+\ell,T))$, and add labels only where $O_{t,c}=1$. Thus the long-regime upper bound of 240 steps is a sampled outage horizon before within-window clipping; in a 168-step window, the clipped interval cannot exceed 168 steps, and pre-existing AWS gaps can further split the final supervised label mask into shorter observed segments. In the realized diagnostics, long-regime sampled intervals have median 155--156 steps across missing rates, while clipped intervals have median 80 steps, 10th--90th percentile range 17--139 steps, and maximum 168 steps. The corresponding supervised label segments have median length 5 steps because only originally observed positions become labels.

The curriculum used in the main experiments is not a temporal schedule over epochs; instead, each training configuration fixes a target block regime and missing rate, and the mask generator samples fresh block positions online for each batch. The model therefore sees many outage realizations under the same failure-mode distribution. Follow-up experiments vary the outage horizon directly, using 24 h, 72 h, and 216 h block settings to test whether ERA5 gains increase as the station-only context weakens.

\subsection{ECBIT Architecture}
ECBIT uses two variate-token encoders. Instead of treating each timestamp as a token, it treats each meteorological variable as a token whose feature vector contains the full temporal trajectory. This representation follows the motivation of inverted time-series transformers \citep{liu2024itransformer}: in multivariate station data, cross-variable attention is often more meaningful than attention across hundreds of individual time steps.

For each AWS variable $c$, the observation token is built from four components: the masked normalized AWS trajectory $\tilde{X}_{:,c}$, the real observation mask $O_{:,c}$, the model input missing mask $M_{:,c}$, and shared time encodings. The time encodings include calendar features for the 3-hourly timestamps and are shared across variables in the same window. The corresponding ERA5 token uses the aligned ERA5 trajectory $E_{:,c}$ and the same time encodings. Each token construction can be written schematically as
\begin{equation}
h^{aws}_c = W_{aws}\,\mathrm{vec}([\tilde{X}_{:,c}, O_{:,c}, M_{:,c}, T_{enc}]),
\end{equation}
\begin{equation}
h^{era5}_c = W_{era5}\,\mathrm{vec}([E_{:,c}, T_{enc}]),
\end{equation}
where $T_{enc}$ denotes the shared time-feature matrix and $\mathrm{vec}(\cdot)$ flattens the length-$T$ trajectory features into one variable token.

In the experiments, the projected token dimension is $d=128$. The AWS and ERA5 streams each use three transformer encoder layers, eight attention heads, a feed-forward width of 256, dropout of 0.1, residual connections, and layer normalization. Transformer encoders produce $Z^{aws}, Z^{era5} \in \mathbb{R}^{C \times d}$. Because $C=5$, attention is computationally small; the model's capacity is spent on representing each variable trajectory rather than on a long timestamp-token attention matrix.

The final ECBIT variant uses gated feature injection. ERA5 tokens are first projected into the AWS embedding space, and a learned vector gate blends ERA5 information into each AWS token:
\begin{equation}
\Delta^{era5} = W_e Z^{era5}, \quad
s = \sigma(W_g [Z^{aws}; Z^{era5}]).
\end{equation}
Here $s_c$ denotes the slice of $s$ corresponding to variable $c$. A missing-variable gate $g_c=\mathbb{1}[\sum_t M_{t,c}>0]$ controls whether ERA5 can alter the AWS representation:
\begin{equation}
Z_c = \mathrm{LayerNorm}(Z^{aws}_c + g_c\, s_c \odot \Delta^{era5}_c).
\end{equation}
The reconstruction head maps each variable token back to a length-$T$ sequence. If a variable has no missing positions, its output is independent of ERA5 after fusion. This is a deliberate bias-control mechanism: ERA5 is allowed to help where AWS evidence is absent, but observed variables are not forced to absorb reanalysis bias. A concat/no-cross fusion variant is retained as an ablation to test whether this gated injection mechanism is actually necessary.

\subsection{Training and Evaluation Procedure}
The full training loop is summarized as follows.
\begin{enumerate}
  \item Load sparse AWS windows, real observation masks, aligned ERA5 windows, and time encodings.
  \item Sample artificial missing labels $A$ from observed positions according to the configured missingness regime.
  \item Mask AWS inputs to form $\tilde{X}$ and encode AWS and ERA5 variate tokens.
  \item Fuse ERA5 into AWS representations only for variables with missing positions.
  \item Decode each variable token into a reconstructed length-$T$ trajectory.
  \item Optimize mean squared error on $A$ only; select checkpoints by validation loss and report test MAE/RMSE on the same artificial-label support.
\end{enumerate}
All neural experiments use AdamW with learning rate $10^{-4}$, weight decay $10^{-4}$, batch size 32, and early stopping with patience 10. The evaluation code uses the same mask generator settings as the corresponding test configuration, making the reported differences attributable to model variant, ERA5 conditioning, and training-mask distribution rather than to changes in metric support.

For a deployed imputed series, observed input values are copied back after decoding:
\begin{equation}
X^{out}_{t,c} = (1-M_{t,c})X_{t,c} + M_{t,c}\hat{X}_{t,c}.
\label{eq:copy-back}
\end{equation}
This post-processing rule is shared conceptually with the stateless baselines, which preserve observed inputs by construction. Reported MAE/RMSE on artificial labels are unaffected by this copy-back because $A_{t,c}=1$ implies $M_{t,c}=1$, but the rule is important for the task definition: imputation fills missing entries without modifying values that remain observed in the input context.
